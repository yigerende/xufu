# 代理厂商与动态/静态，2026-10-31

管理员新增/编辑代理可选择 IPRoyal、Cliproxy、其他，以及动态/静态。列表展示两个字段，凭据仍加密保存且不回显，编辑留空保留原凭据。

地址支持直接粘贴 `host:port:username:password`，默认按 HTTP 代理解析，不需要手动补协议头或会话参数。Cliproxy 动态网关在界面选择 Cliproxy＋动态；保存时规范化并加密原凭据，订单绑定时才添加该单 sid 和15分钟期限。显式 HTTP/HTTPS/SOCKS5/SOCKS5H URL 格式继续支持。

| 厂商与类型 | 新订单的会话规则 |
| --- | --- |
| IPRoyal＋动态 | 原密码 `_session-` 规则：每单独立 session，保留已有国家和有效 lifetime，缺省寿命1小时 |
| Cliproxy＋动态 | 用户名添加/替换 `-sid-<每单唯一标识>-t-15`，固定15分钟；保留账户、地区/州省和密码 |
| 任意厂商＋静态，或其他厂商 | 连接地址/凭据原样使用，不增加、删除或改写供应商会话参数 |

Cliproxy参考：[流量套餐集成手册](https://help.cliproxy.com/zh/faq/traffic-api)。每单生成新的 sid，同一单提链、付款、授权刷新、订阅核实及续费处理复用保存的端点；同单重试不会重新生成。新 sid 请求供应商重新分配出口，不保证与此前 IP 不同。期限到达后遵循现有停止规则，不换 sid 延长原单或重付。

`resources.vendor` 和 `resources.ip_mode` 保存选择。旧资源首次仅按原精确 `geo.iproyal.com` 判为 IPRoyal，其余为其他；类型缺省动态以保持此前行为。用户选择不会在重启时被推断覆盖。新界面缺省其他＋动态；兼容旧管理客户端的创建仍采用原域名规则，更新省略字段则保留原选择。

分配代理时在资源租约锁内同时读取厂商与类型，生成一次并加密冻结至 `order_proxy_sessions`。已有绑定不读取最新厂商重造会话，活动租约期间禁止更改厂商或类型。既有付款前IP比对、随机账单及逐套餐长短链规则保持。独立续费管理和代理质量检测继续直接使用后台原配置。

## 实际连通测试

使用用户提供的 Cliproxy 动态网关，仅请求出口查询服务，未发送账号或付款请求。每次关闭连接并重新连接：SOCKS5H同一sid三次出口均为49.149.66.159，新sid为136.158.17.137；HTTP同一sid三次出口均为49.149.74.231，新sid为136.158.62.249，HTTP四次查询地区均为PH。另用项目实际的prepareOrderProxy与newPaymentClient及现有桌面代理链执行三次独立HTTP连接，出口均为PH/112.202.236.74，均在原8秒请求时限内完成。两组测试采用手册t-15参数；测试覆盖短时间重复连接，不称已等待完整15分钟或保证供应商永不换IP。

本机系统DNS返回代理软件的Fake-IP，独立探针使用公开DNS解析结果通过现有桌面代理建立连接；原应用代理链及出口校验没有改动。最初出口响应读取超时，按HTTP响应边界读取后通过。测试凭据不进入源码、日志或报告。

用户确认会直接粘贴四段地址后，额外核对原生保存接口→加密资源→订单绑定→原单重试，均保持HTTP主机/端口/用户名/密码和900秒期限。真实凭据通过同一四段输入再次联网，最后一次同sid三条独立连接均为PH/112.211.37.42，耗时5.062、4.363、3.160秒。此前两轮复测共出现四次8秒超时及一次成功；所有记录保留，说明地址格式和会话机制可用，但当时线路存在连接波动，不能称全程零失败。未修改请求时限或IP校验来掩盖波动。

隔离测试覆盖厂商/类型组合、旧数据迁移幂等、管理员输入校验和权限、凭据留空保留、活动任务阻止修改、原单重试保持sid及900秒期限。验证及本地更新记录在 `.local/proxy-vendor-mode-20261031/`，发布状态以工作区运维记录为准。
